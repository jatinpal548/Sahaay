# App Icon Setup Instructions

To set your SAHAAY logo as the app icon:

## Android Icons
Replace the following files with your logo (resize to appropriate dimensions):

1. android/app/src/main/res/mipmap-hdpi/ic_launcher.png (72x72px)
2. android/app/src/main/res/mipmap-mdpi/ic_launcher.png (48x48px)  
3. android/app/src/main/res/mipmap-xhdpi/ic_launcher.png (96x96px)
4. android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png (144x144px)
5. android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png (192x192px)

## iOS Icons (if needed)
Replace files in ios/Runner/Assets.xcassets/AppIcon.appiconset/

## Web Icon
Replace web/icons/Icon-192.png and web/icons/Icon-512.png

## Quick Setup
You can use online tools like:
- https://appicon.co/
- https://makeappicon.com/

Upload your "Sahaay Logo.png" and download the generated icon pack, then replace the files above.
